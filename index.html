IAN doesn't live on one server. Every message lands on the nearest edge node, picks up his rules and memory, and streams back in real time.

One message, end to end.

Keep scrolling. The trace opens up and follows a single message from your thumb to the model and back.

message.tracehop 1 / 5

          

          
    
            
  1. You send a message
    Typed or dictated. The app sends your last 12 turns, each capped at 800 characters, and nothing else unless private mode is on.
    2. 
            
  2. The edge worker takes it
    A Cloudflare Worker checks the origin, rate limits by IP and verifies the passcode by comparing SHA-256 digests. The API key lives here as a secret and never reaches the browser.
    3. 
            
  3. The model is called
    The worker adds IAN's system prompt, the hard safety rules and your memory notes, then calls Claude or GPT with a fixed token budget.
    4. 
            
  4. The reply streams back
    Tokens arrive as server-sent events and render as they land. Output is written with text nodes only, so a reply can't inject markup into the page.
    5. 
            
  5. No network? The local core answers
    If the worker can't be reached, an intent-matching core in the browser replies with zero requests. A service worker keeps the app itself available offline.
    6.

Built to be attacked.

      
A public chatbot with a paid API behind it is a target. This is each way in, and what's standing in front of it.

      

        

          
Someone steals the API key
The key is a Worker secret. It isn't in the repo, the page or the app bundle, so there is nothing in the client to steal.

          
Someone runs up the bill
Per-IP rate limit, an origin allowlist, and hard caps on turns, characters and output tokens per request.

          
A reply injects script
Model output is parsed into text nodes. There is no innerHTML in the chat path, and links open with noopener.

          
Passcode guessing
Five wrong tries locks that IP out for ten minutes. The comparison runs over SHA-256 digests so timing doesn't leak a partial match.

          
Memory leaking to strangers
Notes stay in localStorage on your device and are only sent to the worker in private mode. Delete them any time in Settings.

          
Wallet drainers posing as IAN
The prompt forbids asking for seed phrases, keys or wallet connections in every mode, and tells him to warn you if you paste one.

        

      

      
      
Rate limits are held in worker memory, so treat them as a first line. Set a monthly spend cap on your API key as the hard limit.
